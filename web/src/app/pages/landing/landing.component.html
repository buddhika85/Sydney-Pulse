Sydney Pulse

Real-time disruption intelligence for Sydney public transport.

A real-time, event-driven Azure portfolio project. TfNSW GTFS-RT is polled, fanned out through Event Grid + Service Bus, persisted to Cosmos DB, and pushed to the browser via SignalR — deployed via Bicep and GitHub Actions.

View Live Dashboard → View on GitHub

Live vehicles

Poller pulls TfNSW GTFS-RT every 30 seconds. Markers move on the map as vehicles report their positions.

Real-time alerts

Service alerts stream in via Service Bus and SignalR — no polling. The alerts panel updates as TfNSW publishes.

Route filters

Chip strip filters vehicles and alerts by line (T1, T2, T3...). Hovering a chip shows per-line vehicle and alert counts.

How it works

Event-driven pipeline built on managed Azure services. Every arrow is a real message, every box is a running Function or resource.
